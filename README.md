# NotoriusFight

API REST de uma loja de artigos de luta. Projeto da disciplina, adaptado do projeto de referência
[suporteos2026](https://github.com/jeffersonarpasserini/suporteos2026).

Estado do projeto: **Aula 17 — Auditoria e proteção da autenticação**

| Aula | Conteúdo |
|---|---|
| 00 | Início do repositório e versionamento |
| 01 | Preparação do ambiente |
| 02 | Definição do tema e criação do projeto Spring Boot |
| 03 | Modelo de domínio com Java puro |
| 04 | Persistência com JPA, PostgreSQL e Liquibase |
| 05 | Repositories, serviços e transações |
| 06 | Evolução do modelo: fornecedor e estoque mínimo |
| 07 | API REST, DTOs e mapeadores |
| 08 | CRUD completo, estoque, filtros e paginação |
| 09 | Documentação OpenAPI |
| 10 | Pessoas, clientes, colaboradores e vendas |
| 11 | Concorrência de estoque |
| 12 | Autenticação com Spring Security |
| 13 | JWT e Resource Server |
| 14 | Autorização e perfis |
| 15 | Testes e cobertura com JaCoCo |
| 16 | Renovação e revogação de tokens |
| 17 | Auditoria e proteção da autenticação |

## Ambiente

Java 21, Git, PostgreSQL 17, IntelliJ IDEA e Postman.

Copie `.env.example` para `.env` e preencha os valores locais. O `.env` não vai para o Git.
